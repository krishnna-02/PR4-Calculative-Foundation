# 🧠 Calculative Foundation
### Exploring Student Performance Through Linear Algebra

**Turning student marks into mathematical insights using Python.**

## 💡 About the Project

What if student performance could be understood through mathematical patterns instead of marks alone?

This project explores that idea using Linear Algebra techniques on student performance data. It transforms ordinary subject scores into vectors and matrices, then uses mathematical operations and dimensionality reduction to uncover patterns in the data.

Built as a practical foundation project for **Data Science, Artificial Intelligence, and Machine Learning**.

## 🔬 What Makes This Project Interesting?

Instead of only calculating averages, this project explores the mathematical relationships hidden inside student scores.

- 🧮 **Vector Intelligence** — Measure vector magnitude and compare student performance using norms, dot products, and angles.
- 📐 **Geometric Perspective** — Explore cross products, vector projections, lines, planes, and higher-dimensional spaces.
- 🔢 **Matrix Laboratory** — Perform matrix operations, transpose, determinant, and inverse calculations.
- 🧬 **Eigenvalue Exploration** — Understand covariance, eigenvalues, and eigenvectors.
- 🚀 **Dimensionality Reduction** — Apply Principal Component Analysis (PCA) to represent three subject variables using fewer dimensions.
- 📊 **Visual Insights** — Use charts to make mathematical results easier to understand.

## 🛠️ Built With

`Python` · `NumPy` · `Pandas` · `Matplotlib` · `Jupyter Notebook`

## 📂 Project Files

- **calculative_foundation.ipynb** — Complete practical implementation, calculations, visualizations, and interpretations.
- **student_scores.csv** — Dataset containing student marks across multiple subjects.

## 📈 Key Discoveries

- Student score vectors can be compared by measuring the angle between them.
- Matrix operations provide a structured way to analyze multiple students and subjects.
- Covariance and eigenvalues reveal the major directions of variation in student performance.
- PCA demonstrates how multiple subject variables can be summarized with fewer components while retaining much of the data's variance.

*The findings are based on a small educational sample dataset and are intended to demonstrate mathematical techniques.*
